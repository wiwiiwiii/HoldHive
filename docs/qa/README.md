# HoldHive QA Notes

Use this folder when validating `qa` or handing API changes to frontend.

- `acceptance-checklist.md`: end-to-end validation checklist.
- `api-test-cases.md`: curl/Postman-ready backend API test cases.
- `frontend-integration-notes.md`: frontend follow-up items for backend contract changes.
- `defect-log.md`: defects found during validation and regression status.
